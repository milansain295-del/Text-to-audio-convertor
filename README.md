# Text to audio convertor

Simple Flask web app that converts text input to audio.

## Contents
- `app.py` — Flask application entry point
- `templates/index.html` — web UI
- `static/style.css` — styles

## Setup
1. Create a Python virtual environment and activate it.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Notes
- If the app uses additional audio libraries (e.g., `pyttsx3`, `gTTS`), add them to `requirements.txt` and reinstall.

# Text-to-audio-convertor
The Text-to-Audio Converter is an AI-based application that converts written text into natural and understandable speech using Text-to-Speech (TTS) technology. The project allows users to enter any text and instantly generate audio output in different voices and languages.
